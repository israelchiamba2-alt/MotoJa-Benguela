# MotoJá V4 Android — Benguela

Base Android do MotoJá preparada para o lançamento inicial na província de Benguela.

## Incluído nesta versão
- Passageiro, Motorista e Administrador
- 23 municípios/configurações de operação de Benguela
- Faixas de tarifa: curta 300–500 Kz, média 500–1.000 Kz, longa 800–1.500 Kz
- Carteira de passageiro em modo de teste
- Carteira de motorista com acumulação de ganhos
- Comissão MotoJá de 15%
- Pagamento na plataforma em modo de teste
- Opções previstas: Multicaixa Express e ATM
- Solicitação de levantamento do motorista em modo de teste
- Sem dependência do Google Cloud nesta etapa

## Importante
Os pagamentos reais por Multicaixa Express/ATM exigem integração com um parceiro/provedor autorizado. Esta versão não movimenta dinheiro real.
